# Conseil des Conseillers — Adaptations portables

Ce dossier contient les versions du skill **Conseil des Conseillers** adaptées pour les plateformes IA qui ne supportent pas l'installation CLI.

## Fichiers disponibles

| Fichier | Usage |
|--------|-------|
| `one-shot-universal.md` | À coller au début de n'importe quelle conversation |
| `chatgpt-gpt-instructions.md` | System prompt pour ChatGPT Custom GPT (GPT Builder) |
| `gemini-gem-instructions.md` | Instructions pour Gemini Gems |
| `claude-project-instructions.md` | Instructions pour Claude.ai Projects |
| `other-platforms.md` | Guide pour Poe, Copilot, Character.ai, Mistral, Ollama, etc. |

## Démarrage rapide

**Je veux l'utiliser maintenant, sans rien configurer :**
→ Ouvre `one-shot-universal.md`, copie le bloc, colle-le dans n'importe quelle interface IA.

**Je veux un assistant dédié permanent :**
→ Choisis le fichier correspondant à ta plateforme et colle son contenu dans le champ "instructions" ou "system prompt".

## Déclenchement dans tous les cas

Le conseil se lance quand tu :
- Décris un problème complexe avec plusieurs options
- Demandes un arbitrage ou une recommandation stratégique
- Écris **"passe ça au conseil"** ou **"/council"**

## Langue

Toutes les versions détectent automatiquement la langue de l'utilisateur et répondent en conséquence.
